# Bubble Inspeksi

Aplikasi web untuk memberi nomor bubble dan garis leader pada gambar PDF (drawing inspeksi), lalu export hasilnya ke PDF.

## Fitur

- Upload PDF (multi-halaman)
- Bubble bernomor otomatis — klik untuk menaruh, geser untuk memindah, urut ulang otomatis
- Garis leader — 2 klik: bubble + titik yang ditunjuk, garis lurus tanpa panah
- Ukuran bubble 10–64 px, warna garis & isi, opasitas garis & isi (tab Markup)
- Zoom (tombol, slider, Ctrl+roda, cubit), navigasi multi-halaman
- Undo/redo (Ctrl+Z / Ctrl+Shift+Z)
- Export PDF — bubble dan leader tercetak sebagai vektor, sama seperti di layar

## Cara pakai

1. Buka https://alifwildan15.github.io/bubble-inspeksi/
2. Upload file PDF gambar
3. Pilih alat Bubble atau Leader, klik di gambar
4. Export PDF

## Versi Windows

Aplikasi desktop (Electron) tersedia di [bubble-inspeksi-desktop](https://github.com/alifwildan15/bubble-inspeksi-desktop).
